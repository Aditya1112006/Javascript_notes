## 📚 Detailed Modules & Concepts Mastered

### 1️⃣ Core Fundamentals
- **Variables & Data Types:** Primitive & reference types (`let`, `const`, `var`, strings, numbers, booleans, undefined, null).
- **Operators:** Arithmetic (`+`, `-`, `*`, `/`, `%`), Relational (`>`, `<`, `>=`, `<=`, `===`, `!==`), Logical (`&&`, `||`, `!`), Ternary (`condition ? a : b`).
- **Control Flow:** `if`, `else if`, `else`, `switch` statements, truthy vs falsy values.
- **Strings & String Methods:** Immutability, `slice()`, `indexOf()`, `replace()`, `trim()`, method chaining.
- **Loops:** `for`, `while`, `do...while`, `nested for`, loop control with `break` & `continue`, `for...of` loops.

### 2️⃣ Data Structures & Objects
- **Arrays:** Indexing, pushing/popping, shifting/unshifting, slicing, splicing, multi-dimensional arrays.
- **Objects:** Key-value mapping, accessing properties (`dot` vs `bracket`), adding, updating, deleting properties, nested objects, array of objects.
- **Math Object:** `Math.PI`, `Math.abs()`, `Math.floor()`, `Math.ceil()`, `Math.random()`, generating random range integers.
- **JSON:** JavaScript Object Notation syntax, `JSON.parse()` for deserialization, `JSON.stringify()` for serialization.

### 3️⃣ Functions, Scopes & Execution Context
- **Functions:** Function declarations, function expressions, default arguments, return values.
- **Scopes:** Function scope, Block scope, Lexical scope & closures.
- **`this` Keyword:** Dynamic binding in objects/methods vs lexical binding in Arrow Functions.
- **Higher-Order Functions & Timers:** Passing functions as arguments, returning functions, `setTimeout()`, `setInterval()`, `clearInterval()`.

### 4️⃣ Modern ES6+ & Functional Array Methods
- **Array Iterators:** `forEach()`, `map()`, `filter()`, `reduce()`, `every()`, `some()`, `find()`.
- **Destructuring:** Array destructuring, Object destructuring, default values during destructuring.
- **Rest & Spread Operators:** Unpacking arrays/objects (`...spread`), parameter collecting (`...rest`).

### 5️⃣ Asynchronous JavaScript & Networking
- **Callback Patterns:** Asynchronous call stack, Web APIs queue, event loop, handling Callback Hell.
- **Promises:** Creating promises, promise states (pending, resolved, rejected), handling resolution with `.then()` and errors with `.catch()`, promise chaining.
- **Async / Await:** Writing asynchronous code that reads like synchronous code, `try...catch` inside async functions.
- **APIs & HTTP Requests:** Native `fetch()` API, HTTP Methods (GET), response JSON parsing.
- **Axios:** Using Axios library for cleaner API calls, sending custom Headers, building API image viewer apps (Cat API & Dog API).

### 6️⃣ DOM Manipulation & Web Events
- **DOM Selection:** `document.getElementById()`, `document.getElementsByClassName()`, `document.querySelector()`, `document.querySelectorAll()`.
- **DOM Traversal & Modification:** `parentElement`, `children`, `innerText`, `textContent`, `innerHTML`, `setAttribute()`, `classList` (`add`, `remove`, `toggle`).
- **Events:** Event listeners (`addEventListener`), Mouse events (`click`, `mouseenter`), Keyboard events (`keydown`), Form events (`submit`, `preventDefault`), Event Delegation & Bubbling.
